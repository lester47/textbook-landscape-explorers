# 📖 課本景觀 360 探險隊

國小社會四上（南一版）第三單元第一課〈家鄉的景觀〉課本 p.44～49 提到的 14 個景觀，做成 360° 寫實全景闖關教材。
獨立專案，與「南投家鄉景觀探險隊」、食農系列不共用存檔或圖檔（程式引擎相同）。

| 路線 | 站 | 景觀 | 課本 | 時光機 |
| :-- | :-- | :-- | :-- | :-- |
| 自然 | N1～N6 | 月世界、佳樂水、日月潭、臺東森林公園、碧潭、清水斷崖 | p.45～46 | — |
| 人文 | C1～C5 | 艋舺龍山寺、恆春古城、磺溪書院、大天后宮、打狗英國領事館官邸 | p.45、47 | — |
| 變遷 | V1～V3 | 臺中中央公園、山佳車站、霧峰林家 | p.48～49 | 三格 |

- 流程：首頁 → 暖身任務（課本 p.44 臺南旅遊地圖，選 3 個景點並判斷景觀類型）→ 臺灣地圖選路線 → 各站 7 線索＋1 彩蛋、4 題 → 終極任務三關 → 證書。
- 三條路線可任選順序，每條路線內一站一站解鎖。
- 終極任務：① 14 站分自然／人文 ② 3 個變遷景點判斷原因 ③ 課本句子配對景觀。
- 寫實 AI 圖都會標示「AI 生成示意圖」，每站有「📷 真實照片」連結到官方或旅遊網站。
- 證書 14 枚徽章兩排各 7 枚（位置在 `data/eras.json` 的 `certLayout`）。
- 存檔鍵：`textbook_landscape_explorers_progress`。

## 怎麼開啟

- 直接雙擊 `index.html`（可離線）。
- `開啟網站.bat`：本機伺服器 http://127.0.0.1:8092。
- 學生獨立版：`dist/課本景觀360探險隊_學生獨立版.html`。
- 網址加 `?teacher`：全部開放、略過暖身，畫面中央顯示紅色準心與 x、y 百分比，用來校準線索。

## 換上 Codex 正式圖

依「Codex 生圖任務清單」把圖放進：`pano/`（含 `hotspots_XX.json`）、`timemachine/`、`ui/`（徽章、`taiwan_map.jpg`、`tainan_warmup.jpg`、`hotspots_tainan.json`）、`cert/`、`mascot/`。
然後雙擊 `同步素材.bat`（或 `python sync_assets.py`）。正式圖優先，沒有才用 `_placeholder/` 示意圖；線索位置會自動套用。
草稿檔（例如 `N1_moonworld_draft.png`）不會被讀取，請以正式檔名交付。

## 改內容

全部文字都在 `data/eras.json`，改完執行 `同步素材.bat`。
